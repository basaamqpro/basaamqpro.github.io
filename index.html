3D Car Visual animation

I created this project long time ago, when I was trying to learn html and css I created the body of the car and the wheels using normal div

Car Body

The position and size of the car parts were callibrated using browser inspector tools, I adjusted the values untill they were right Then plotted the data in the array, then used a for loop to create the divs with that data.

Car Wheels

The cars wheels were the most intresting part of the project, it was a combination of using css transform rotateX and rotateY and translateZ RotateX was used to rotate the wheel vertically, translateZ was used to create a distance between the alloys and the center of the wheel Rotatey was the most intresting part, because it would place each alloy in different position in respect to rotateX and translateZ and rotateY had to be incremented by a number around 19 to spread the alloys around the wheel to create a circle.

Then I had to create four different wheels and 3d position them for their respective position X and Y and Z, which was caliberated using chrome inspector tools and adjusted values, then the I simply used the for loop to place them, using absolute positioning left and top and translateZ to create the front and back wheels.

3d geometric visual

This project was created to understand 3d positioning, movement and calculations It has a 3d cube that moves in 3d space, the cube will stop moving when it hits one of the 4 cubes but can move around it

Calculations

This projects uses many and multiples calculations at the same time, it uses the distance formula to calculate the distance between the moving cube and the 4 cubes It also uses the pythagorean theorem to calculate the distance between the moving cube and the 4 cubes It also uses the law of cosines to calculate the angle between the moving cube and the 4 cubes It also uses the law of sines to calculate the angle between the moving cube and the 4 cubes It also uses the law of tangents to calculate the angle between the moving cube and the 4 cubes It also uses the law of cotangents to calculate the angle between the moving cube and the 4 cubes

How it works

Move the mouse around the screen or your finer in a circle to see how the cube moves.

3d Calculations

It calculates the postion of the mouse to the center of the screen, and calculates the related angle and distance, then it uses the angle and distance to calculate the new position of the moving cube, and then it checks if the new position is colliding with any of the 4 cubes, if it is colliding it will stop moving, if not it will move to the new position when you move the mouse away from the 4 cubes.
